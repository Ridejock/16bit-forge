# 16bit-forge 

*Forged for the 16-bit era.*

16bit Forge is a Super Nintendo / Super Famicom (SNES) emulator written in C++20, with a Dear
ImGui frontend on SDL3.
It aims for accuracy first: the CPU, PPU and APU are cycle-based, and the enhancement chips
are emulated at the instruction level rather than with game-specific hacks.

> **No games are included.** You need your own legally dumped ROMs (and, for a few
> enhancement chips, firmware dumps). See [Games and firmware](#games-and-firmware).

## Features

- **CPU** - 65C816 with cycle timing, DMA/HDMA, IRQ/NMI timing, the multiply/divide unit.
- **PPU** - all background modes including Mode 7, windows, colour math, hi-res and
  interlace, mid-scanline register effects, offset-per-tile.
- **APU** - SPC700 and S-DSP: BRR decoding, Gaussian interpolation, ADSR/GAIN envelopes,
  noise, pitch modulation, echo with the 8-tap FIR filter.
- **Enhancement chips** - see the table below.
- **MSU-1** - streamed data and CD-quality audio tracks for ROM hacks and homebrew.
- **Frontend**
  - ROM library (a `roms/` folder next to the program) and recent files
  - 10 save state slots with thumbnails (Shift+F1-F10 to save, F1-F10 to load), with a
    short on-screen message in the game window (View > On-screen messages turns it off)
  - rewind and fast-forward (hold or toggle), frame advance, and a timeline of rewind
    snapshots (click one to play from there, right-click to save that moment to a slot)
  - battery saves and real-time-clock saves, written automatically
  - cheats: Game Genie, Pro Action Replay and raw address codes
  - memory watch and RAM search (M, or Debug > Memory watch / RAM search). Watches are saved
    per game. Freeze holds a value until you close the game, and the Cheat button makes a
    normal code (an SRAM watch can't). Each watch has a permanent id and is read once a frame
  - run timer and splits (View > Run timer). Game time counts emulated frames beside real
    time, with personal-best deltas, a sum of best, and attempt counts. A new personal best
    asks before it is saved. Auto-splits come from memory watches. Rewinding past a split
    undoes it. Splits import and export as LiveSplit `.lss` files, and the overlay can sit in
    any corner of the game picture. A cheat, freeze, or memory edit marks the run "modified".
    Timing is NTSC. Keypad 1/8/2/3/5 are split, undo, skip, reset, and pause
  - GPU renderer (Vulkan / Direct3D 12 / Metal through SDL_GPU) with filter shaders:
    nearest, sharp-bilinear, xBR, ScaleFX, CRT scanlines, CRT-Lottes (optional curvature),
    NTSC composite and S-Video signal simulation into a CRT (presets in `shaders/presets.ini`);
    an SDL_Renderer fallback for older systems
  - integer scaling, 8:7 aspect, fullscreen game window
  - audio sync or video sync, volume and MSU-1 volume, WAV recording
  - log panel with per-component trace channels
- **Controllers** - keyboard and gamepads (hotplug, press-to-bind), Multitap (up to 5
  players), SNES Mouse and Super Scope.

### Supported enhancement chips

| Chip | Example games | Status | Needs firmware |
|---|---|---|---|
| Super FX (GSU-1 / GSU-2) | Star Fox, Yoshi's Island, Doom | Emulated | No |
| SA-1 | Super Mario RPG, Kirby Super Star | Emulated | No |
| Cx4 | Mega Man X2, X3 | Emulated | No (optional `cx4.data.rom`) |
| S-DD1 | Star Ocean, Street Fighter Alpha 2 | Emulated | No |
| SPC7110 (+ RTC-4513) | Far East of Eden Zero, Momotarou Dentetsu Happy | Emulated | No |
| OBC1 | Metal Combat | Emulated | No |
| DSP-1 / 1B / 2 / 3 / 4 | Pilotwings, Super Mario Kart | Emulated | Yes |
| ST010 / ST011 | F1 ROC II, Hayazashi Nidan Morita Shogi | Emulated | Yes |
| ST018, S-RTC, Super Game Boy | | Detected only (runs as plain ROM) | |

The game names are only there to say which chip is which; none of them come with the
emulator.

## Games and firmware

- **Bring your own legally dumped ROMs.** No game ROMs or chip firmware files are included in
  this repository or in the release downloads, and please don't open issues or pull
  requests that link to them.
- Put games (`.sfc` / `.smc`) in a `roms/` folder next to the program, or open them from
  **File > Open ROM**.
- **Firmware**: the DSP-n and ST010/ST011 chips have a program ROM inside the chip. Games
  that use them need a dump of that firmware in a `firmware/` folder next to the program
  (`dsp1.rom`, `dsp1b.rom`, ... `st011.rom`; see `firmware/README.txt` in the release). The
  Cx4 math tables are generated by the emulator, so no file is needed for it.
- The sound chip's 64-byte boot ROM (IPL) is built in, as in other SNES emulators; see
  THIRD_PARTY_NOTICES.md.
- Saves go next to the program: `saves/` (battery RAM, `.srm`, and clock, `.rtc`),
  `states/` (save states, `.sst`), `cheats/` (`.cht`), `watches/` (`.wch`), `splits/` (`.lss`), `logs/`. Settings are in
  `16bitForge.ini`; a `snes_emulator.ini` from before the rename is read once if there is no
  `16bitForge.ini` yet.

## Controls

Default keyboard layout (change it under **Emulation > Controls**; gamepads work out of the
box):

| SNES | Keyboard | Gamepad |
|---|---|---|
| D-pad | Arrow keys | D-pad / left stick |
| B / A / Y / X | Z / X / A / S | South / East / West / North |
| L / R | Q / W | Shoulder buttons |
| Start / Select | Enter / Right Shift | Start / Back |

| Action | Key | Gamepad |
|---|---|---|
| Rewind (hold) | Backspace | Left trigger |
| Fast-forward (hold) | Tab | Right trigger |
| Fast-forward toggle | ` (backtick) | Right stick click |
| Pause / run | Space | |
| Memory watch / RAM search | M | |
| Timer: split / undo / skip / reset / pause | Keypad 1 / 8 / 2 / 3 / 5 | |
| Timeline | click a thumbnail; right-click saves that moment to a slot | |
| Save state 1-10 | Shift+F1 ... Shift+F10 | |
| Load state 1-10 | F1 ... F10 | |
| Fullscreen | F11 (Esc leaves) | |

Command line: `16bitForge [rom.sfc] [--renderer gpu|sdl] [--filter <preset>]
[--screenshot out.bmp] [--exit-after-frames N] [--record-audio out.wav]`.

## Building

You need CMake 3.24+, a C++20 compiler and Git. SDL3 and Dear ImGui are downloaded by CMake.

Filter shaders are compiled at build time with
[SDL_shadercross](https://github.com/libsdl-org/SDL_shadercross). By default CMake builds it
once per machine into a cache folder (this includes DirectXShaderCompiler and takes a while
the first time). To use a shadercross you already have, pass
`-DEMERALD_SHADERCROSS_EXECUTABLE=/path/to/shadercross`.

### Windows (Visual Studio 2022, MSVC)

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
build\Release\16bitForge.exe
```

Tip: if the shadercross build fails on long paths, set the `EMERALD_CACHE_DIR` environment
variable to a short folder such as `C:\emc`.

To make the release zip (`16bitForge-<version>-windows-x64.zip`): `tools\package_windows.ps1`
(or `cd build; cpack -C Release`).

### Linux

```sh
# Debian/Ubuntu packages for SDL3's video/audio backends:
sudo apt install build-essential cmake ninja-build git clang python3 \
  libx11-dev libxext-dev libxrandr-dev libxcursor-dev libxi-dev libxss-dev libxtst-dev \
  libxkbcommon-dev libwayland-dev wayland-protocols libdecor-0-dev libegl-dev libgl-dev \
  libasound2-dev libpulse-dev libpipewire-0.3-dev libdbus-1-dev libudev-dev
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
./build/16bitForge
```

With GCC 14 or newer, install Clang too: the shadercross tool is then built with Clang
(GCC 14 miscompiles DirectXShaderCompiler).

### Tests

`ctest` runs twelve suites (CPU, PPU, APU, save states, enhancement chips, audio sync, input,
filter presets, memory watches, the run timer, frame pacing, threading). They need no ROM files: they use hand-written instruction tests and
a small test ROM generated in code. To also run free test ROMs (for example PeterLemon's or
gilyon's SNES test suites), point `BITFORGE_TEST_ROMS_DIR` (CMake option or environment variable)
at a folder of `.sfc` / `.spc` files, or pass ROM paths on a suite's command line.
